About this project

Small talk helps people build rapport, but it is through deep and meaningful conversations (DMCs) where people build intimacy and truly learn about each other. This site is a compendium of questions you can use to kick-start a DMC, if you are struggling to think of good things to talk about.

Every question has a short note on why it works, links to similar questions, and tags so you can browse by theme. Use the search bar to find questions by keyword, or hit Surprise me in the navigation for a random pick.

The source code lives on GitHub.
